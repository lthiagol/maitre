## Conventions

- **Docs state intent; ADRs record choices.** Change the ADR first.
- **Every principle cites evidence.** No citation ⇒ it's a preference; label it as one.
- **Human-facing docs stay short.** See [AGENTS.md](../AGENTS.md#house-style).
- **Open questions are marked, not hidden.** Drafts carry an explicit `## Open questions`.
